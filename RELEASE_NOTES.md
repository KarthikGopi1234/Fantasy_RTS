### ✨ Features - Ambitious Scope
#### Resources (5 types)
Food, Wood, Gold, Mana, Stone with caps and gather rates

#### Ages (3)
Village Age, Kingdom Age, Mythic Age with unlocks

#### Buildings (8 + variants)
Town Hall, House, Barracks, Archery, Stable, Mage Tower, Wall, Market

#### Units (8)
Villager, Swordsman, Archer, Knight, Healer, Mage, Golem, Dragon

#### Tech Tree
Economy and Military upgrades

#### Core Systems
GameManager, ResourceManager, TechTree, SaveManager, World, MapGenerator, BaseUnit state machine, BaseBuilding production queue

#### Controls (Mobile-First)
Drag-box selection, tap-to-move, right-click attack/gather, building placement

#### UI
Resource HUD, selection panel, build/train menus, minimap, health bars

#### Assets (101 files)
Procedurally generated via Python/Pillow - app icon, tiles, buildings, units, UI
